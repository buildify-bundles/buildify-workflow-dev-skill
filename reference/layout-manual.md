# 排版细节与手算兜底

**有 Node 时不用读这份。** `build.mjs` / `layout.mjs` 已经按下面的规则算好坐标。这里只给两种情况用：本机没有 Node 18+ 必须手算坐标；或者要向用户解释排版为什么长这样。

## 脚本做了什么

`scripts/layout.mjs` 移植自控制台 `applyLayout.js`（回边不参与分层 + 按出口顺序固定分支左右 + Dagre 分层 + 主链加权 + 拉直短错位 + 扇出与出口文字加层距 + 同层起点对齐 + 外层过宽扇出拆排 + 多段并排 + 分组包络 + 批注放进空白）。**各层都不折行**，再长的主链也是一条。卡片按 **248×63** 兜底；控制台里 `summary` 很长、卡片被撑宽时，用户再点「自动排列」会略有差异，属于正常现象。出口文字的宽度按字数估算（全角 11、半角 6.6）。

| 项 | 说明 |
|---|---|
| 只排一个分组 | `--group <分组 id>` 对应控制台分组右键「自动排列组内节点」：只重排这个分组（含嵌套子分组），框的左上角不动、宽高按内容重算；组外节点不动，外层分组装不下时只向右、向下放大。不能和改方向的 `--direction` 一起用 |
| 写什么 | 执行节点的 `position`、`sourcePosition` / `targetPosition`；分组框的 `position`、`style.width/height`；组内子节点相对框的 `position`；批注落位后的 `position`（不改批注宽高）。缺 `errors` 时补 `{}` |
| 不写什么 | 不写 `dimensions`，也不给执行节点写 `width` / `height`（控制台按内容测量卡片） |
| 收尾 | 整图排版时，有顶层盒子落到 `x < 40` 或 `y < 24` 时，把所有顶层节点一起平移进来。`--group` 不做这一步 |
| 退出码 | 0 写好；1 只在 `--check` 时出现，表示坐标还不是自动排列结果；3 文件或图结构有错（边指向不存在的节点、连到分组框或批注、`parentNode` 不是分组框、id 重复、`--group` 指的不是分组框） |

**回连和分支顺序**：从入口做深度优先遍历，连回遍历栈里上游节点的边算回连，不参与分层，回连由控制台在外侧绕。同一节点的多条出边按出口首次出现的顺序排左右（`TB` 从左到右、`LR` 从上到下）。

**主链优先**：先找最长的一条路径当主链，让 Dagre 优先把它排直，旁支分到两侧。只有一条入边、和上游中心线差得不多（不到 48 或节点间距）的节点会沿交叉轴挪过去对齐，消掉短 Z 形线。

**出口文字让位**：层距留够放出口文字的空间（文字 + 两侧箭头 22 + 余量 6；扇出、汇合时再加共用主干 48）。`TB` 普通单线层距 74 已够；扇出 2 路、或多路汇入同一节点时净空约 **120**。`LR` 出口名 7 个汉字起单线层距会比 140 大；扇出 2 路或汇合时 3 个汉字起、扇出 3 路及以上时 6 个汉字起就会变大。

**过宽扇出拆排**：只在画布外层做，分组内部不拆排。一个节点直接连出 **≥6** 个下游，且都是没有出边的叶子、整层只有它们、宽度超过 8 张卡片的 1.3 倍时，才交错排进几排。默认卡片下单个节点扇出 **11 个**下游起拆。

**共用收尾节点**：一个节点没有自己的出边，且至少 **3** 个上游各自还有别的出边（如各步失败都接到同一个「失败返回」）时，把它放到主体尽头（`TB` 下方净空 **120**；`LR` 右侧净空 **170**），交叉轴对齐主体中线。

**批注**：不进 Dagre。排完节点后先在这一层节点的外接矩形里，从左上角起按 24 一格找一块不压住任何节点（净空 **24**）的空白；放不下时贴在节点外侧（`TB` 右侧、`LR` 下方，净空 **24**），多张沿流向接着排，在分组里时框随之撑开。多张批注按初始坐标的先后（先 `y` 后 `x`，再按 id）依次放。

## 手算兜底（没有 Node 时）

规则与脚本相同。过宽扇出拆排只能靠脚本，手算时保持一条主链 / 一排兄弟，不要自己折行。执行节点按卡片 **宽 248、高 63** 占位，给每个执行节点写 `sourcePosition` / `targetPosition`，不要混用方向。

步进 = 该方向上的卡片边长 + 净空。同层沿流向对齐：`TB` 同一层 `y` 相同，`LR` 同一层 `x` 相同。分叉时父节点在交叉轴上居中盖住两侧子节点。画布第一张卡片从 `{ "x": 45, "y": 24 }` 起。

| `direction` | 锚点 | 主链（这一层出度 1） | 同层兄弟（全图最大出度 ≤2） | 扇出 |
|---|---|---|---|---|
| `TB`（默认） | `sourcePosition: "bottom"`，`targetPosition: "top"` | 同一 `x`，`y += 137`（净空 **74**） | 同一 `y`，相邻 `x += 298`（净空 **50**） | 上一层有普通节点出度 **≥ 2**：下一层改为 `y += 183`（净空 **120**）。出度 **≥ 3** 时兄弟改为 `x += 288`（净空 **40**）。多路汇入同一节点的那一层也至少 `y += 183` |
| `LR` | `sourcePosition: "right"`，`targetPosition: "left"` | 同一 `y`，`x += 388`（净空 **140**） | 同一 `x`，相邻 `y += 135`（净空 **72**） | 出度 **= 2** 不加长。出度 **≥ 3**：下一层改为 `x += 418`（净空 **170**），兄弟改为 `y += 119`（净空 **56**） |

一层里只要有一个普通节点达到上表扇出，**下一层整层**一起沿流向加长，只作用于同一段。分组框的出度不算。组内与画布共用这张表。

```
TB（出度 2，下一层净空 120）          LR（出度 2，层距不加长，兄弟净空 72）

        [判断] x=194 y=24              [判断] x=45 y=91.5
       /                \                 |                \
[A] x=45 y=207    [B] x=343 y=207   [A] x=433 y=24    [B] x=433 y=159
```

`TB` 里两个子节点的 `x` 是 `45` 和 `45 + 298`，父节点 `x = (45 + 343) / 2 = 194`。`LR` 里子节点 `y` 是 `24` 和 `24 + 135`，父节点 `y = (24 + 159) / 2 = 91.5`。

- 主链优先走直线（`TB` 同 `x`，`LR` 同 `y`）；不要交叉、不要穿过别的节点、不要让文字压在卡片上。回连成环时节点仍按主链排，回连交给控制台绕线
- 分组框、批注不要写 `sourcePosition` / `targetPosition`
- 批注和分组框各占一块矩形，框外节点、另一块分组、批注都按**矩形外缘**留空

### 多段并列

各段先从局部原点 `(0, 0)` 按上表排段内坐标，再整段平移。不要让一段的扇出去拉长另一段。

| `direction` | 各段对齐 | 下一段从哪开始 | 第一段原点 |
|---|---|---|---|
| `TB` | 顶对齐（各段外缘最上沿都在 `y = 24`） | `x = 上一段最右外缘 + 64` | 外缘左上角 `{45, 24}` |
| `LR` | 左对齐（各段外缘最左沿都在 `x = 45`） | `y = 上一段最下外缘 + 72` | 外缘左上角 `{45, 24}` |

外缘 = 这段里所有顶层盒子（卡片或分组框）的外接矩形。段的先后按需求里的顺序。

### 分组框

- 先按组内步进从局部原点排好子节点，得到包络 `contentW × contentH`，再算 `width = max(contentW + 96, 240)`，`height = max(contentH + 132, 112)`。子节点整体放到相对框 `x = 48`、`y = 84` 起（内容比最小尺寸还小时在框内居中）。单节点就是 **344×195**，子节点在 `{48, 84}`；`TB` 主链两张是 **344×332**。
- **组内有回连**时留白加宽：`TB` 回环走偏向的一侧（不偏时走右侧），那一侧留白至少 **146**，回连起点所在的底边至少 **120**；`LR` 回环走底侧，底边留白至少 **146**，右边至少 **120**。回连终点是组内第一个节点时，`TB` 顶边、`LR` 左边也至少 **120**。多条回环重叠时每层再加 14。
- **框外按框的外缘留空**，分组当一个整体，它的出度不加长层距。`TB`：框下方的下一顶层盒子 `next.y = 框 y + height + 74`，并相对框水平居中；同一层里分组框和普通卡片 `y` 相同。`LR`：`next.x = 框 x + width + 140`，框与同层卡片按框体垂直居中。互不连线的几个框按「多段并列」排。
- 分组内部不折行、不拆排。

### 批注

直接放在节点外侧：`TB` 在右侧（`x = 节点最右缘 + 24`，顶边与最上节点对齐），`LR` 在下方（`y = 节点最下缘 + 24`，左边与最左节点对齐）。批注矩形宽默认 **320**，HTTP 接口文档 **480**（最小 180、最大 480）；高按正文估 `28 + 17×正文行数 + 20×标题行数`，限制在 50–480。
